# Sudoku Web

## v24 업데이트

- 21개 선명한 색상 테마와 난이도 연동 색상 해금
- 기존 기록을 보존하는 별도 난이도 잠금 진행도 및 난이도별 평균 완료 시간
- 이메일 계정 로그인과 RLS 기반 기기 간 기록 동기화
- 강화된 극한 퍼즐, 스도쿠 테스트, 달인 금색 테마와 서명형 PNG 자격증

별도 서버 없이 GitHub Pages에서 실행되는 모바일 친화형 스도쿠 웹게임입니다.

## 주요 기능

- 매우 쉬움부터 극한까지 7단계 난이도
- 극한은 17개 단서와 유일해를 유지하며, 28개 변형 중 실제 탐색 난도가 가장 높은 판을 선택
- 모든 난이도에서 유일한 해답이 보장되는 퍼즐
- 자동 저장과 미완료 게임 이어하기
- 새 게임 시작 전 진행 중인 게임 삭제 확인
- 메모, 지우기, 되돌리기, 일시정지, 이어하기
- 실수 3회 시 즉시 실패
- 같은 칸에 같은 오답을 다시 입력해도 실수는 한 번만 반영
- 멀티플레이 입력 확인 중에는 다음 숫자 입력을 잠시 잠가 지연된 응답과 새 입력이 뒤섞이지 않도록 보호
- 서버에서도 퍼즐의 해답이 정확히 하나인지 검사한 뒤에만 방 생성
- 저장된 퍼즐·정답의 무결성을 복원할 때 다시 검사하고, 손상된 정답 데이터는 고유 해답으로 자동 복구
- 극한을 제외한 게임마다 무작위 1~4개 힌트와 1% 힌트 실패 확률

현재 오프라인 캐시 버전: `sudoku-v23`
- 점수, XP, 레벨, 싱글 현재/최고 연승 및 누적 통계
- 멀티플레이 경기 수, 승패, 승률, 경기 시간, 무실수 승리, 별도 연승 통계
- 승리 시간과 최고 점수는 싱글·멀티플레이 통합 기록으로 표시
- 멀티플레이 최고 점수는 Supabase의 서버 기록과 동기화되어 통합 최고 점수에 반영
- 싱글은 닉네임 없이 플레이할 수 있으며, 매 판 선택한 경우에만 닉네임과 점수를 공개 랭킹에 등록
- 배경음악 없이 메뉴·입력·오답·힌트·일시정지·온라인·승패 효과음 및 켜기/끄기 설정
- 각 동작은 해당 종류에 속한 효과음 2~3개 중 하나만 무작위 재생
- 두 사람이 같은 퍼즐로 겨루는 2인 경쟁 멀티플레이
- 수동 방 코드 입력과 QR 참가 링크, 후면 카메라 QR 스캔 지원
- 멀티플레이도 매 판 참가자별 랭킹 등록 여부를 선택하며 기본값은 제외
- 모드·난이도별 온라인 랭킹
- 자동·세로·가로 화면 배치 선택 및 설정 저장
- 새로고침 후 싱글 게임 자동 이어하기 및 멀티플레이 방 재연결
- 멀티플레이 나가기 시 확인 후 방과 저장 세션 삭제
- 15가지 색상 테마
- Galaxy를 포함한 모바일 세로·가로 화면 및 safe area 대응
- 기하학적 스도쿠 아이콘과 Web App Manifest를 이용한 PWA 설치
- Service Worker를 이용한 단일 플레이 오프라인 실행

## 멀티플레이

- **2인 경쟁:** 두 참가자가 같은 퍼즐을 각자 풀며, 먼저 완성한 참가자가 승리합니다.
- 방 코드는 8자리이며 방장과 참가자, 정확히 2명만 참가할 수 있습니다.
- 대기실의 QR을 다른 기기에서 스캔하면 방 코드가 자동 입력되며, 카메라 권한을 거부해도 코드를 직접 입력할 수 있습니다.
- 방과 참가자 변경은 토큰으로 검증되는 Supabase RPC를 통해서만 처리됩니다.
- 게임 상태 변경 알림은 Supabase Realtime Broadcast로 전달되며, 실제 상태는 서버에서 다시 검증합니다.

온라인 게임에는 힌트·일시정지·되돌리기가 적용되지 않습니다. 경쟁의 공정성을 위한 제한입니다.

## Supabase

공개 테이블은 모두 RLS가 활성화되어 있고 직접 접근 권한이 없습니다. 브라우저에는 공개 가능한 publishable key만 포함하며 서비스 역할 키는 사용하지 않습니다.

<https://2550563-jung.github.io/sudoku/>

## 저장 데이터

기존 사용자 데이터와 호환되는 다음 `localStorage` 키를 사용합니다.

- `sudoku-game-v5`: 진행 중인 게임
- `sudoku-profile-v5`: 통계, XP, 레벨, 연승
- `sudoku-theme-v5`: 선택한 색상 테마

손상되거나 이전 형식인 저장 데이터는 가능한 범위에서 정규화해 복구합니다.

## PWA

아이콘 파일은 모두 저장소 루트에 있으며 `manifest.json`, `index.html`, `sw.js`도 루트 상대 경로로 참조합니다. Service Worker 캐시 버전은 `sudoku-v21`이며 핵심 파일에는 캐시 갱신용 버전 주소를 사용합니다. 배포 후 기존 홈 화면 바로가기는 삭제하고 Chrome에서 사이트를 다시 연 뒤 앱을 재설치해야 새 아이콘이 확실히 적용됩니다.

## 제3자 라이브러리

QR 생성에는 `qrcode-generator 1.4.4`(MIT), 카메라 영상의 QR 해석 대체 경로에는 `jsQR 1.4.0`(Apache-2.0)을 사용합니다. 각 라이선스는 `vendor` 폴더에 포함되어 있습니다.
