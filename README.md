# Sudoku Web

GitHub Pages용 스도쿠 웹앱입니다.

## 업로드
압축을 풀고 아래 파일들을 저장소 루트에 업로드하세요.
- index.html
- style.css
- app.js
- manifest.json
- sw.js

## GitHub Pages
Settings → Pages → Deploy from a branch → main → /(root) → Save

예상 주소:
https://2550563-jung.github.io/sudoku/

## 기능
- 쉬움 / 보통 / 어려움
- 색상 테마 7종
- 자동 저장 및 이어하기
- 메모 모드
- 되돌리기
- 힌트
- 실수 3회 제한
- 타이머 / 일시정지
- 모바일 반응형
- 오프라인 캐시
